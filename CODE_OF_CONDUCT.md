# Code of Conduct

We want this project to be a welcoming place for people interested in Xenosaga, game preservation and software development.

## Expected conduct

- Treat others with respect, regardless of experience, identity or background.
- Keep feedback constructive and directed at the work rather than the person.
- Respect accessibility needs, personal boundaries and privacy.
- Accept that people may disagree about technical decisions.

Harassment, threats, discriminatory slurs, personal attacks, sexual harassment and publishing someone's private information without permission are not acceptable.

## Reporting and moderation

For abusive content on GitHub, use its reporting tools. For project-specific concerns, contact a maintainer privately if a private contact method is available. Do not publish sensitive personal information in an issue. This project does not currently publish a dedicated confidential reporting address.

Maintainers may remove inappropriate content, restrict participation or report serious abuse to GitHub. Moderation should be proportionate to the conduct and protect affected participants' privacy.

These expectations apply to project issues, pull requests, discussions and other project spaces managed by maintainers.
